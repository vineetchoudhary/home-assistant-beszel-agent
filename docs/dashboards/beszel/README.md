# Beszel dashboards

Dashboard templates for Beszel Bridge's MQTT entities, using standard Home Assistant cards.

- [Server overview](server-overview.yaml): status, resource usage and connection diagnostics.
- [Server detail](server-detail.yaml): current readings, history and a link to Beszel.
- [Storage and SMART](storage-health.yaml): separate filesystems, combined totals, disk health and readable uptime.

Complete [Bridge setup](../../../beszel_bridge/DOCS.md), then follow the [dashboard setup guide](SETUP.md) to import a template and replace its example entity IDs.
