# Changelog

## 0.21.1.3

- Add `enable_all_entities` to enable new and existing integration-disabled entities in bulk while preserving entity IDs, history and explicit user disables.
- Add optional `history_retention_days` for daily detailed-history cleanup of selected Bridge entities, disabled by default and preserving Home Assistant's statistics and global retention policy.

[View GitHub release v0.21.1.3](https://github.com/vineetchoudhary/home-assistant-beszel-agent/releases/tag/v0.21.1.3)

## 0.21.1.2

- Add per-filesystem readings, weighted storage totals and overlap exclusions.
- Add SMART health, disk details and readable power-on time, update age and uptime.
- Expose hardware, container, service, storage-pool, probe, package and alert metrics.
- Preserve existing entities and history, with detailed sensors disabled by default.

[View GitHub release v0.21.1.2](https://github.com/vineetchoudhary/home-assistant-beszel-agent/releases/tag/v0.21.1.2)
